Diagram-as-code · four views · single-file HTML · v0.4.0

Architecture diagrams that fail the build when they lie.

Every diagram-as-code tool turns text into a picture. None of them can tell you when the picture started lying. truss binds each node to a path in the repository, and truss check fails your build when that path is gone.

      02 — The source

      Text you can review. No coordinates.

      The layout is automatic and always is: cycles broken, layers assigned, crossings counted and minimised, group boxes pushed clear. A diagram you have to hand-place is a diagram nobody updates.

      • -> a call
      • ~> an asynchronous message
      • code= the binding: a path or a glob
      • kind= service · store · queue · infra · client · external · job
      • dugum every keyword also has a Turkish spelling
      title  Payment Platform
flow   down
group edge "Edge"
group core "Core services"
node web    "Storefront"  in=edge kind=client  code=apps/web/**
node api    "API Gateway" in=core kind=service code=services/api/**
node pay    "Payment"     in=core kind=service code=services/payment/**
node bus    "Event bus"   in=core kind=queue
node bank   "Acquirer"            kind=external note="third party"
web -> api : REST
api -> pay : charge
pay ~> bus : payment.captured
pay -> bank : authorise

      03 — In CI

      One line in a workflow

      - run: npx @talkdedsec/tlk-truss check docs/architecture.truss --ci

      Or the action

      - uses: Talkdedsec/tlk-truss@v0.4.0
  with:
    sources: docs/*.truss
    uncovered: true

      Turn the question around

      --strict flags nodes with no binding at all. --uncovered asks which directories no diagram claims; several sources are checked together and the coverage is their union.

      $ truss check docs/*.truss --root . --uncovered
! /srv/shop  W401  no node claims "workers/"
✓ every code binding resolves — 21/26 nodes bound to code

      Speed is never the problem; legibility is. Past roughly thirty nodes the picture stops explaining anything, so split the story into several diagrams.

      05 — Install

      One package. No build step.

      One HTML file per diagram: no network calls, dark and light themes, pan and zoom, search, a detail panel per node, SVG and PNG export.

      npm install -g @talkdedsec/tlk-truss
      truss draw examples/payments.truss -o payments.html
